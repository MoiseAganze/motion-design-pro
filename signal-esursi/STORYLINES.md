# ESURSI — Signalement national · storylines

Sujet : https://signal.minesursi.gouv.cd — plateforme nationale de signalement des irrégularités
dans l'enseignement supérieur (Ministère ESURSI, RDC). Film ~60 s, 1920×1080, voix off FR
(ElevenLabs « Audrey », McVZB9hVxVSk3Equu8EH), musique fournie (124 BPM).

## A — « Le voyage d'un dossier » (RECOMMANDÉ, construit)

*Pourquoi :* c'est l'histoire qu'un inconnu suit sans effort — une étudiante signale, le Ministère
voit, agit — et elle contient exactement les trois parcours demandés (téléphone → carte → Mac).

- **Device / form :** un seul objet traverse les mondes (la référence du dossier) · chaîne
  objet-à-objet : chaque plan se termine sur ce qui ouvre le suivant.
- **Ce qu'on voit :** les abus réels (catégories officielles) claquent sur les couleurs du drapeau,
  se taisent ; l'affiche officielle « Signalez les abus » se révèle puis devient l'écran d'accueil d'un
  téléphone ; le formulaire en 8 étapes se remplit ; à l'envoi, la référence s'envole, tombe sur
  Kinshasa dans la carte nationale (reconstruite, complète), puis atterrit dans la liste des dossiers
  sur un MacBook où un agent le traite. Fin : proposition de valeur + carte de marque.
- **2 premières secondes :** plein cadre bleu RDC, « Vente de points » en Source Sans 3 Black
  géant, coupe sur le temps suivant → jaune, « Faux diplômes ».
- **Beats :** hook (abus) → silence → révélation (affiche) → téléphone (8 étapes) → envol de la
  référence → carte nationale → Mac (dossier, statut, messagerie) → valeur → carte de marque.
- **Look :** la charte du site : bleu #0057B8, marine #002654, ciel #007FFF, jaune #F7D618,
  rouge #CE1021, bande tricolore oblique ; Source Serif 4 (titres) + Source Sans 3 (texte).
- **Son :** la piste fournie démarre à 48,43 s pour que sa coupure (2 mesures) tombe sur le
  « silence » et que la reprise frappe la révélation ; la fin naturelle du morceau ferme le film.

## B — « Une voix dans l'amphi » (non construit)

Un moment dans la journée d'une étudiante : 7 h 42, un message « 50 000 FC pour ta note »,
le pouce hésite, puis ouvre signal.minesursi.gouv.cd. Tout le film reste dans sa main (plan
unique, caméra épaule simulée) jusqu'au code de suivi ; le Ministère n'apparaît qu'en
contrechamp final. Plus émotionnel, mais montre peu la carte et le traitement.

## C — « Le pays s'allume » (non construit, le pari audacieux)

Vol continu au-dessus de la carte de la RDC : chaque province est une escale, chaque escale
une fonctionnalité réelle (signalement à Kinshasa, statistiques à l'Équateur, suivi en Ituri…).
Spectaculaire, mais le formulaire sur téléphone et le traitement sur Mac deviennent des
vignettes au lieu d'être des parcours.
