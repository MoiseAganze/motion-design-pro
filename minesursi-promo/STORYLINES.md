# MINESURSI — pistes narratives

## A. « Le Ministère dans la poche » (retenue)

Device : le texte porte l'argument, puis la fonctionnalité réelle comme preuve. Forme : chaîne d'objets — la bande tricolore de l'app (bleu, jaune, rouge) est le fil conducteur : elle souligne les trois mots du ministère, devient le bord du bandeau-titre, puis le soulignement du logo final.

- 0–2 s : fond marine, « Enseignement supérieur · Recherche · Innovation » s'allument un par un sur le temps pendant que la bande tricolore se dessine.
- Beats : crochet typo → le téléphone monte sous la bande → toucher « Communiqués » → onglet Actualités → retour Accueil, vidéos ESURSI TV → onglet Plus (Offres & bourses, Centres de recherche) → défilement vers « Mon espace » (Vérifier un établissement, Mes documents) → retour Accueil → le fond devient marine, la bande file sous « MINESURSI », slogan.
- Look : marine #0B2B5E de la barre de l'app, sols pleins aux couleurs du drapeau (jaune, bleu, rouge) et un blanc froid, Montserrat 800, captures réelles dans un téléphone graphite.
- Son : la musique fournie entre au 4e temps, la section complète tombe sur « Minesursi » (impact), clics doux sur les touchers.

## B. « La veille d'inscription » (non retenue)

Un étudiant hésite entre deux établissements la veille de s'inscrire ; il ouvre l'app, vérifie l'agrément. Écartée : l'écran de résultat de vérification n'est pas dans les captures, il faudrait l'inventer.
